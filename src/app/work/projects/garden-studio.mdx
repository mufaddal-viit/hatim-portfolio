A room this small only works if the storage is structural. The shelving runs wall
to wall and doubles as the desk support, which keeps the floor completely clear —
the one move that stops a studio of this size feeling like a shed.

The window is deliberately oversized for the footprint. From the desk you see
garden rather than fence, and the room borrows depth it does not actually have.
